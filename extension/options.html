Terminal in Chrome

Native host

The extension talks to a small Python program on your Mac that runs the shell. Install it once with ./install.sh from the project folder.

Extension ID:

Shell

Profiles

A profile overrides the shell, directory and look for the tabs it opens. Blank fields inherit the global settings above/below. Open one with the ▾ next to + (or right-click +).

Keyboard shortcuts

Ctrl+Shift+TNew terminal tab
Ctrl+Shift+WClose pane (last pane closes the tab)
Ctrl+Shift+D / Ctrl+Shift+ESplit right / split down
Ctrl+Shift+← ↑ → ↓Focus the pane in that direction
Ctrl+Shift+[ / ]Previous / next terminal tab
⌘↑ / ⌘↓Previous / next prompt (shell integration)
Ctrl+Shift+BBroadcast input: off → this tab → all tabs → off
Ctrl+Alt+Shift+BExclude / include the current pane while broadcasting
⌘C / ⌘VCopy selection / paste
⌘KClear screen
⌘FFind in scrollback (Enter / Shift+Enter, Esc closes)
⌘+ / ⌘- / ⌘0Font size bigger / smaller / reset
⌘-click a linkOpen it in a new browser tab
⌘-click a file pathOpen it with the OS (or your "Open files with" command)

Global shortcuts (open a terminal from any page) are configured at chrome://extensions/shortcuts.
